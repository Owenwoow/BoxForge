## 0. TL;DR（给执行者的快速上手）

做一个 **参数化 3D 收纳盒生成器**：用户填几个参数（尺寸、圆角、隔板布局、镂空开关）→ 程序生成一个带圆角、可加递归隔板、可选药丸镂空的盒子 → 导出 STL 供 3D 打印。

- **语言 / 建模内核**：Python + [CadQuery](https://github.com/CadQuery/cadquery)（基于 OpenCASCADE 真实 CAD 内核，**不是** mesh 库）
- **配置**：嵌套 YAML
- **UI（第二阶段）**：Streamlit **Web UI**（浏览器内运行，非桌面程序）——滑块 + 实时 3D 预览 + 导出
- **交付分两阶段**：先跑通建模核心（脚本 + YAML），再套 Streamlit 界面
- **硬约束**：盒子长、宽 ≤ 250mm（打印板 256×256 留余量）

**明确不要做的事**：不要用 MATLAB；不要用 OpenSCAD 做圆角/抽壳（minkowski 凑圆角慢且易错）；不要用纯 mesh 库（如 trimesh 直接建模）做倒角抽壳。

## 1. 项目介绍

### 1.1 背景
参考 MakerWorld 的「参数化模型编辑器」（一个 `Box Designer.scad` 挂在网页上的交互形态）：用户拖几个滑块、填几个参数，就能生成一个定制盒子模型并下载。本项目要实现同类工具，但功能更强（递归隔板 + 免支撑药丸镂空），且用 Python 生态而非 OpenSCAD。

### 1.2 目标产物
一个圆角收纳盒，具备：
1. 自定义尺寸（长/宽/高、壁厚）
2. 四个竖直角的圆弧过渡 + 水平棱的倒角/圆角
3. 可在任意位置递归添加横/纵隔板
4. 可选的「药丸形（胶囊形）45° 免支撑镂空」，作用于底面和/或隔板
5. 导出 STL 用于 3D 打印

### 1.3 最终使用方式
3D 打印。导出格式 **STL**。打印板尺寸 **256×256**，故模型长宽做硬性上限约束。

## 2. 需求详述（含原始交流中固化的决策）

> 以下每条都来自与需求方的多轮确认，**执行者不得擅自更改这些已定决策**，除非在「§7 已知取舍」中被标注为可选增强。

### 2.1 盒体本体
- **尺寸自定义**：外部长 / 宽 / 高，均为参数。壁厚参数化。
- **圆角分两类，独立参数，半径均可自由调节**（需求方明确区分过，且强调半径要能调）：
  - **竖直四角圆角**（`corner_radius`）：连接顶面与底面的那 4 条竖直棱做圆角 → 俯视时四角圆润（类似手机外壳）。**半径可调**，设 0 即直角。
  - **水平棱倒角/圆角**（`edge_fillet`）：顶面周边、底面周边的水平棱做圆角 → 侧视时边缘不是死直角，摸上去不割手。顶、底可分别设不同半径（例如让顶面「微微圆润」），**两者均可独立调节**，设 0 即直角。典型「微弧不割手」取小值 0.5~1mm。
  - **顶口内外双棱（重要，易漏）**：抽壳后顶口是有壁厚的开口，因此顶沿实际有**两条棱——外沿棱和内沿棱**。真正割手的是这两条棱，尤其内沿棱。`edge_fillet.top` 必须**同时对内、外两条顶沿棱倒角**，让整圈顶口摸上去都圆润，不能只倒外沿而漏掉内沿。底沿若为封闭底面则通常只有外沿一条棱，按实际几何处理。
  - **半径合法性**：圆角半径受几何限制，不能超过相邻边长/壁厚允许的上限，校验阶段需做上限保护（如 `corner_radius < min(长,宽)/2`、`edge_fillet < 高` 且顶沿圆角受 `wall` 壁厚约束 `edge_fillet.top < wall`），超限时钳制到安全值或报错提示。
- **实现要点（重要）**：隔板、镂空操作会改变棱边编号，**筛选棱边必须按方向/位置筛选，禁止按索引硬编码**，否则模型尺寸或结构一变，圆角就选错棱。

### 2.2 隔板系统 —— 递归二分（BSP）

需求方在「方案A 递归二分」与「方案B 区域内网格」之间，**明确选择了方案A（递归二分，追求极致灵活性）**，并接受其取舍（见 §7）。

- **数据结构**：递归二叉空间分割树（BSP tree）。
- **单次操作**：把「一个矩形区域」沿 X 或 Y 方向，用一块隔板一刀切成「两个子区域」。
- **递归性**：任意子区域可继续独立细分，**互不影响其他区域**。这正是需求方要的核心 —— 「分完之后可以再单独给某个区域分，也可以贯穿整体分」。
  - 「贯穿整体分」= 在根区域直接切。
  - 「只在某一格里再分」= 在对应子节点上切。
- **切割位置**：支持两种写法且可自由调配 —— **比例**（如 `0.5`、`0.333`）或**绝对尺寸**（如 `"30mm"`）。
- **隔板厚度**：参数化。
- **隔板高度**：可选参数，允许低于盒壁高度（不到顶）。

### 2.3 药丸镂空系统（免支撑）

需求方提供了参考图：**底面上一整片倾斜 45° 的药丸形（pill/胶囊形）孔阵列**，规律铺满。设计意图是 3D 打印时孔顶自成拱形过桥，**不塌陷、免支撑**。

固化决策：
- **角度固定 45°**（最佳免支撑角度），不做成可调。
- **孔尺寸**：只暴露「孔大小」一个参数；**孔间距按孔径自动计算**铺满，不单独暴露。
- **应用面**：底面、各隔板均可镂空，**每个面独立开关，可加可不加**。
- **外墙永不镂空**（需求方反复强调）。
- **自动留四周实边框**：镂空阵列靠近区域边缘时，自动保留一圈实心边框（参考图中那种四周实框效果），边框宽度取合理默认值。
- **实现思路**：生成覆盖目标面的 45° 药丸孔阵列 → 与「目标面内缩边框后的区域」求交（裁掉出界/压边的孔）→ 对目标面实体做布尔切除。

### 2.4 尺寸与打印约束
- 长、宽 **≤ 250mm**（256 板留 6mm 安全余量），超限**抛出明确错误并拒绝生成**。
- 高度可设 Z 轴上限（按打印机，默认给个宽松值如 250mm，可配置）。

## 3. 技术栈与依赖

### 3.1 选型理由（供执行者理解，勿推翻）
| 需求 | 为什么用 CadQuery |
|---|---|
| 圆角 (fillet) | 内置真实 B-rep 圆角，稳定 |
| 抽壳 / 挖空 (shell) | 内置 `.shell()`，壁厚均匀 |
| 布尔运算（隔板合并、镂空切除）| OpenCASCADE 内核，稳健 |
| STL 导出 | `cq.exporters.export(...)` 一行搞定 |

**为什么不用**：
- OpenSCAD：圆角靠 minkowski 凑，慢且易错，复杂抽壳吃力。
- 纯 mesh 库（trimesh 等直接建模）：倒角/抽壳不可靠。
- MATLAB：非实体建模工具，3D 显示是画科学数据的，做不出圆角盒子实时预览 + STL 导出；跨 Python 调用只会引入双环境依赖问题。**明确排除**。

### 3.2 依赖清单

**阶段一（建模核心）**
```
python >= 3.10, < 3.13   # CadQuery 对 3.13 支持视版本而定，先用 3.11/3.12 稳妥
cadquery >= 2.4          # 建模内核 (pip install cadquery)
pyyaml                   # 读 YAML 配置
```

**阶段二（Web UI）额外**
```
streamlit                # 参数界面 + 交互
# 3D 预览可用以下任一：
#   - streamlit 内嵌 stpyvista / pyvista  (推荐,实时旋转查看)
#   - 或先导出 STL 再用 <model-viewer> Web 组件预览
```

**安装示例**
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install cadquery pyyaml
# 阶段二再: pip install streamlit stpyvista pyvista
```

> **注意**：CadQuery 的 OpenCASCADE 二进制较大，`pip install cadquery` 可能耗时。若 pip 装不上，退路是用 conda：`conda install -c conda-forge -c cadquery cadquery`。

## 4. YAML 配置规范（对外接口，已定稿）

这是用户唯一需要编辑的东西。程序读它 → 构建模型。

```yaml
box:
  size: [120, 80, 40]          # 外部 [长, 宽, 高] mm。长/宽 ≤ 250 硬校验
  wall: 2                      # 外墙壁厚 mm
  corner_radius: 8             # 竖直四角圆角半径 mm，可调，0=直角
  edge_fillet:                 # 水平棱圆角半径 mm，顶底分开，均可调，0=直角
    top: 2
    bottom: 1

partitions:                    # 递归二分树。null 表示该区域不再细分
  split:
    axis: x                    # x 或 y
    at: 0.5                    # 比例(0~1) 或 绝对尺寸字符串 "30mm"
    thickness: 1.5             # 该隔板厚度 mm
    height: null               # null=到顶; 数值=隔板高度 mm(可不到顶)
  children:
    - split: {axis: y, at: "30mm", thickness: 1.5, height: null}
      children: [null, null]   # 左半再横切成两块,都不再分
    - null                     # 右半不再分

hollow:
  hole_size: 8                 # 药丸孔的宽度 mm (只调这个)
  angle: 45                    # 固定 45,勿改
  border: auto                 # 自动留实边框 (或给数值指定边框宽 mm)
  faces:
    bottom: true               # 底面是否镂空
    partitions: true           # 隔板是否镂空(true=所有隔板;后续可细化为逐块)

export:
  format: stl
  tolerance: 0.1               # 弧面细分精度,越小越精细
  filename: box_output.stl
```

### 递归树语义（伪代码，消除歧义）
```
build_partitions(region, node):
    if node is null:
        return []                      # 叶子,不再分
    axis, at, thickness = node.split
    pos = resolve(at, region, axis)    # 比例→绝对坐标; "30mm"→30
    sub_a, sub_b = region.cut(axis, pos, thickness)   # 一刀分二,中间留隔板
    wall = make_wall(region, axis, pos, thickness, node.split.height)
    walls = [wall]
    walls += build_partitions(sub_a, node.children[0])
    walls += build_partitions(sub_b, node.children[1])
    return walls
```

## 5. 程序架构与执行步骤

### 5.1 建议文件结构
```
box_generator/
├── config.yaml              # 用户编辑的配置样例
├── main.py                  # 入口: 读config → 生成 → 导出
├── box_builder/
│   ├── __init__.py
│   ├── body.py              # 盒体 + 圆角 + 抽壳
│   ├── partitions.py        # 递归二分隔板
│   ├── hollow.py            # 45° 药丸镂空阵列
│   ├── validate.py          # 尺寸约束校验 (长宽≤250 等)
│   └── export.py            # STL 导出
└── app.py                   # 阶段二: Streamlit 界面
```

### 5.2 建模流程（核心算法顺序）
1. **校验**：读 YAML → 校验长宽 ≤ 250、参数合法性，不过就报错退出。
2. **盒体**：按外部尺寸建实心长方体。
3. **竖直角 + 底沿圆角（抽壳前）**：
   - 按**方向**筛选 4 条竖直棱 → 应用 `corner_radius`。
   - 按**位置**筛选底面周边水平棱 → 应用 `edge_fillet.bottom`。
   - （棱边一律按方向/位置筛选，禁止索引硬编码。）
4. **抽壳**：`.shell(-wall)`，留均匀外墙，顶面开口（收纳盒无盖）。
5. **顶口内外沿圆角（抽壳后）**：抽壳后顶口才出现内、外两条沿棱，此时按位置筛选这两条棱 → 同时应用 `edge_fillet.top`（防割手，尤其内沿）。
   > 顺序说明：竖直角圆角建议放在抽壳前以获得稳定的角柱；顶口内沿棱只有抽壳后才存在，故顶沿圆角**必须在抽壳之后**。执行者若发现抽壳前对顶沿倒角会被抽壳破坏，即印证此顺序。
6. **隔板**：按递归树在内腔生成隔板实体，布尔并入盒体。
7. **镂空**：对底面、各隔板（据开关）生成 45° 药丸孔阵列 → 内缩边框求交 → 布尔切除。**外墙不参与**。
8. **导出**：STL，按 tolerance 细分。

### 5.3 药丸镂空实现细节（易错点，展开写）
```
生成单个药丸孔:
    一个 2D 胶囊形 = 一个矩形两端各加一个半圆 (obround)
    宽度 = hole_size, 长度 = 可设为 hole_size * k (k≈2~3, 内部常量)

阵列铺满:
    在目标面平面内,建立一个网格
    间距 = hole_size + gap, gap 由 hole_size 自动推算(如 gap = hole_size * 0.4,
          需保证桥接壁厚 >= 一个喷嘴宽,建议 gap >= 0.8mm 并可下限保护)
    整个阵列绕面法线旋转 45°

留实边框:
    target_area_inner = 目标面轮廓向内偏移 border 宽度
    有效孔 = 药丸阵列 ∩ target_area_inner   (裁掉压边/出界的孔)

切除:
    把有效孔沿面法线拉伸成贯穿柱体 → 从目标面实体布尔减去
```
> 免支撑关键：45° + 药丸圆头，使每个孔顶部是斜面/拱形，打印逐层收口不塌。执行者勿把药丸改成正圆或水平放置，会破坏免支撑特性。

## 6. 分阶段交付

### 阶段一：建模核心（先做，必须先跑通）
- 交付：`main.py` + `box_builder/*` + `config.yaml`
- 验收：改 `config.yaml` → `python main.py` → 得到一个带圆角 + 递归隔板 + 药丸镂空的盒子，导出合法 STL，可在切片软件中打开无错误、免支撑可打印。
- 目的：验证建模逻辑正确，UI 是后续的事。

### 阶段二：Streamlit Web UI（需求方已明确选定 Web UI 形态）
- 交付：`app.py`
- **界面形态：Web UI（浏览器内运行），基于 Streamlit**。运行 `streamlit run app.py` 后起本地服务，浏览器访问 `localhost:8501` 使用；左侧参数控件、右侧 3D 预览，与需求方参考的 MakerWorld 网页编辑器同类形态。**不做桌面 GUI（Qt/CQ-editor 等），不用 MATLAB。** 纯 Python，无需手写 HTML/CSS/JS。
- 内容：尺寸、**圆角半径（竖直四角 + 顶/底水平棱，各一个滑块，可调至 0）**、隔板/镂空的滑块与开关 → 实时 3D 预览 → 「生成」按钮导出 STL 下载。
- 3D 预览实现：Streamlit 内嵌 `stpyvista`/`pyvista` 做可旋转实时预览；退路是先导出 STL 再用 `<model-viewer>` Web 组件展示。
- 复刻需求方看到的 MakerWorld 那种「拖参数→实时预览→下载」体验，全程 Python。
- 默认本地运行（仅本机浏览器可访问）；如需他人访问，可后续部署到服务器或 Streamlit Cloud（非阶段二必做）。

## 7. 已知取舍与可选增强

- **方案A（递归二分）的取舍**：递归二分切出的「十字/田字格」，中间交点**不保证完美对齐**（左右两侧独立横切，高度可能不一致）。需求方**已知并接受**此取舍以换取灵活性。
- **可选增强（非必做）**：若后续觉得规整田字格场景不便，可再加一个「整体网格」快捷入口（每区域直接指定 `行×列`，交点对齐），与递归树并存。**阶段一不做**。
- **逐块镂空**：当前 `hollow.faces.partitions` 是「所有隔板统一开关」。若需求方后续要「逐块隔板单独控制镂空」，在递归树节点上加 `hollow: true/false` 字段即可扩展。

## 8. 给执行者的注意事项清单（checklist）

- [ ] 棱边筛选一律按**方向/位置**，禁止索引硬编码。
- [ ] 长/宽 > 250mm 必须报错拒绝，别静默裁剪。
- [ ] 外墙**绝不**镂空，只有底面和隔板可镂空。
- [ ] 药丸孔：固定 45°、圆头、只暴露孔大小、间距自动、四周留实边框。
- [ ] 镂空孔要**贯穿**目标板厚并正确布尔切除。
- [ ] 收纳盒**顶面开口无盖**（除非需求方另说）。
- [ ] 圆角半径可调（竖直四角、顶/底水平棱独立），并做上限钳制，防止超几何极限导致建模失败。
- [ ] 顶口**内、外两条沿棱都要倒角**（防割手），且顶沿圆角在**抽壳之后**做。
- [ ] STL 导出后自检：无非流形、无破面，可切片。
- [ ] 阶段一先跑通再做 UI。
- [ ] 全程 Python + CadQuery，不引入 MATLAB / OpenSCAD。
