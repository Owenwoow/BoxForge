# 参数化收纳盒生成器 — 使用手册

> 对应实现：[执行计划](参数化收纳盒生成器_执行计划.md) 中固化的方案。本手册面向**实际使用者**，讲怎么装、怎么改参数、每个参数改了会发生什么、出错了怎么办。

---

## 1. 这是什么

一个命令行 + 网页两用的参数化 3D 收纳盒生成器：

- 改几个数字 / 拖几个滑块 → 生成一个带圆角、可加递归隔板、可选 45° 免支撑镂空的收纳盒
- 导出 **STL**，直接丢进切片软件打印
- 建模内核是 [CadQuery](https://github.com/CadQuery/cadquery)（真实 CAD 内核，不是近似 mesh）

两种用法：

| 方式 | 适合场景 | 入口 |
|---|---|---|
| 命令行（阶段一） | 写脚本批量生成、自动化、CI | `main.py` + `config.yaml` |
| 网页 UI（阶段二） | 手动调参、实时看效果、下载 | `streamlit run app.py` |

两者共用同一套建模代码（`box_builder/`），参数含义完全一致。

## 2. 安装

### 2.1 环境要求

- **Python 3.10 ~ 3.13**（CadQuery 官方稳妥支持到 3.12，本项目在 **3.13** 上验证通过；**不要用 3.14**，CadQuery 的 OCP 二进制轮子目前没有 3.14 版本，装不上）
- Windows / macOS / Linux 均可

如果电脑上装了多个 Python 版本，用 `py -0p`（Windows）确认有没有 3.10~3.13，指定用那个版本建虚拟环境。

### 2.2 建虚拟环境并装依赖

```bash
# Windows（用某个 3.10~3.13 版本的 python.exe，不要用系统默认可能是 3.14 的那个）
"C:\Python313\python.exe" -m venv .venv

# 激活虚拟环境，cmd.exe 和 PowerShell 语法不一样：
.venv\Scripts\activate.bat      # cmd.exe
.venv\Scripts\Activate.ps1      # PowerShell

pip install -r requirements.txt
```

> **不激活虚拟环境也能跑**：装完依赖后，任何时候都可以不激活，直接用完整路径调用 `.venv\Scripts\python.exe` / `.venv\Scripts\streamlit.exe`。激活只是图个之后能少打点路径。终端里直接敲 `streamlit run app.py` 报"不是内部或外部命令"，通常就是忘了激活虚拟环境（`streamlit` 只装在 `.venv` 里，不是全局命令）。

`requirements.txt` 内容：

```
# 阶段一：建模核心
cadquery>=2.4
pyyaml

# 阶段二：Streamlit 网页 UI（3D 预览用 CDN 加载的 Three.js，不需要额外 python 包）
streamlit
```

> `cadquery` 会连带装 OpenCASCADE (OCP)、VTK 等一堆二进制依赖，包体积大（几百 MB），首次安装耐心等几分钟。若 `pip install cadquery` 装不上，退路是用 conda：`conda install -c conda-forge -c cadquery cadquery`。

### 2.3 验证安装

```bash
python -c "import cadquery as cq; print(cq.Workplane('XY').box(10,10,10).val().Volume())"
```

能打印出 `999.99...` 左右的数字就说明装好了。

## 3. 快速开始

### 3.1 命令行方式（阶段一）

```bash
cd box_generator
python main.py config.yaml
```

成功会打印：

```
Exported box_output.stl
```

`box_output.stl` 就在当前目录，直接拖进 Bambu Studio / Cura / PrusaSlicer 等切片软件查看、打印。

改 `config.yaml` 里的数字 → 重新跑一遍命令 → 得到新模型。不传参数默认读同目录下的 `config.yaml`：

```bash
python main.py            # 等价于 python main.py config.yaml
python main.py my_box.yaml  # 也可以指定别的配置文件
```

### 3.2 网页 UI 方式（阶段二）

先激活虚拟环境（见 §2.2），再运行：

```bash
cd box_generator
streamlit run app.py
```

没激活虚拟环境的话，用完整路径直接调用一样能跑（不需要先激活）：

```powershell
E:\Code\BoxForge\.venv\Scripts\streamlit.exe run app.py
```

终端会打印一个本地地址（通常是 `http://localhost:8501`），浏览器打开即可。左侧拖滑块调参数，右侧实时看 3D 预览（鼠标拖动旋转、滚轮缩放），满意了点「下载 STL」。

默认只有本机能访问；要给别人用得部署到服务器或 Streamlit Cloud（不在本手册范围内）。

## 4. YAML 配置详解

完整字段说明（对照 `config.yaml` 示例）：

```yaml
box:
  size: [120, 80, 40]          # [长, 宽, 高] mm，长宽必须 ≤ 250（超了直接报错，不会帮你裁剪）
  wall: 2                      # 外墙壁厚 mm
  corner_radius: 8             # 竖直四角圆角半径 mm，0 = 直角
  edge_fillet:
    top: 1                     # 顶口圆角 mm（同时倒外沿+内沿两条棱），上限约 wall/2
    bottom: 1                  # 底面圆角 mm，0 = 直角

partitions:                    # 递归二分隔板树，整段可以是 null（不要隔板）
  split:
    axis: x                    # 沿哪个方向切：x 或 y
    at: 0.5                    # 切割位置：0~1 的比例，或 "30mm" 这种带单位的绝对尺寸
    thickness: 1.5             # 这块隔板的厚度 mm
    height: null                # null = 到顶；填数字 = 隔板矮一截，比如 20 表示只有 20mm 高
  children:
    - split: {axis: y, at: "30mm", thickness: 1.5, height: null}
      children: [null, null]   # 左边那块再横切一刀，切完两块都不再分
    - null                     # 右边那块不再分

hollow:
  hole_size: 8                 # 药丸孔宽度 mm，唯一需要调的镂空参数
  angle: 45                    # 固定 45，改了也会被强制拉回 45（打印免支撑的关键角度）
  border: auto                 # 自动留边框；也可以填数字如 3 指定边框宽度 mm
  faces:
    bottom: true                # 底面要不要镂空
    partitions: true            # 隔板要不要镂空（当前是整体开关，所有隔板一起开/关）

export:
  format: stl
  tolerance: 0.1                # STL 网格精度，越小越精细、文件越大、导出越慢
  filename: box_output.stl
```

### 4.1 字段取值范围与自动纠错行为

| 字段 | 硬限制（超了报错退出） | 软限制（超了自动钳制+打印警告） |
|---|---|---|
| `box.size[0]` 长 | `> 250mm` 报错 | — |
| `box.size[1]` 宽 | `> 250mm` 报错 | — |
| `box.size[2]` 高 | `> z_max`（默认 250mm）报错 | — |
| `box.wall` | `<= 0` 报错；太厚（`wall*2 >= min(长,宽)`）报错 | — |
| `box.corner_radius` | `< 0` 报错 | 超过 `min(长,宽)/2 * 0.9` 会被钳到这个安全值 |
| `edge_fillet.top` | `< 0` 报错 | 超过 `wall/2 * 0.9` 会被钳到这个安全值（**注意不是 wall，是 wall 的一半**，见 §6.1 原因） |
| `edge_fillet.bottom` | `< 0` 报错 | 超过 `min(高, min(长,宽)/2) * 0.8` 会被钳到这个安全值 |
| `hollow.hole_size` | `<= 0` 报错 | — |
| `hollow.angle` | — | 强制改回 45，打印警告 |
| `hollow.border` | `< 0` 报错 | `auto` 时取 `max(wall, hole_size*0.5)` |
| `export.tolerance` | `<= 0` 报错 | — |

命令行模式下，硬限制触发会打印 `[error] ...` 并以非零退出码结束；软限制触发只在 stderr 打印 `[warn] ...`，程序继续跑。网页 UI 下硬限制会在页面顶部显示红色错误框。

### 4.2 隔板递归树语法

`partitions` 要么是 `null`（整个盒子不要隔板），要么是一个 `{split, children}` 节点：

- `split.axis`：`x`（沿长度方向切一刀，切完东西两半）或 `y`（沿宽度方向切一刀，切完南北两半）
- `split.at`：
  - `0` 到 `1` 之间的小数 → 按**比例**切（`0.5` = 正中间）
  - `"30mm"` 这种带 `mm` 后缀的字符串 → 按**绝对尺寸**切，从该区域自己的起始边算起
- `split.thickness`：这一刀隔板的厚度 mm
- `split.height`：`null` 表示隔板顶到盒口；填数字表示隔板矮一截（从内腔底部往上量）
- `children`：长度固定为 2 的数组，`[切完的第一块的后续处理, 切完的第二块的后续处理]`，每一项要么是 `null`（不再切），要么是另一个 `{split, children}` 节点（继续递归细分）

**关键理解**：切完一刀产生两个子区域后，两个子区域互不干扰，可以分别继续细分，也可以其中一个不再分。这就是"田字格"和"只切一半"都能做的原因。

**示例 1：简单十字分四格**

```yaml
partitions:
  split: {axis: x, at: 0.5, thickness: 1.5, height: null}
  children:
    - split: {axis: y, at: 0.5, thickness: 1.5, height: null}
      children: [null, null]
    - split: {axis: y, at: 0.5, thickness: 1.5, height: null}
      children: [null, null]
```

**示例 2：只在左半边加一块矮隔板，右半边不动**

```yaml
partitions:
  split: {axis: x, at: 0.5, thickness: 1.5, height: null}
  children:
    - split: {axis: y, at: 0.4, thickness: 1.5, height: 15}   # 只有15mm高，不到顶
      children: [null, null]
    - null
```

**已知取舍**：递归二分产生的十字格，中间交点不保证完美对齐（因为左右两侧是独立横切的，高度、位置可能有细微差异）。这是为了换取"任意区域独立细分"的灵活性而接受的代价，如果一定要交点对齐的规整网格，需要手动把 `at` 值算好让两侧一致。

### 4.3 镂空 `hollow` 细节

- **只暴露 `hole_size`**：孔间距、孔的长宽比例（药丸长度 = 宽度 × 2.5）都是程序自动算好的，不用你操心
- **`angle` 别改**：写死 45° 是为了保证打印时孔顶部能自然收口成拱形、不塌陷、不用支撑。改了配置文件里的值也会被程序强制拉回 45
- **外墙永远不镂空**：`hollow.faces` 只能控制 `bottom`（底面）和 `partitions`（隔板），没有让你选外墙的选项——外墙镂空这个功能本身不存在，是设计上刻意去掉的
- **`border` 留边框**：孔阵列贴近区域边缘时会自动被裁掉，只留下靠边缘的一圈实心边框，`auto` 模式下边框宽度取 `max(壁厚, 孔径的一半)`；也可以填具体数字强制指定

## 5. 网页 UI 控件对照表

| UI 分组 | 控件 | 对应 YAML 字段 | 备注 |
|---|---|---|---|
| 盒体尺寸 | 长 / 宽 / 高 / 壁厚 滑块 | `box.size`, `box.wall` | 长宽滑块上限就是 250mm，物理上滑不过界 |
| 圆角 | 竖直四角圆角 | `box.corner_radius` | 滑块上限自动跟随长宽联动（`min(长,宽)/2`） |
| 圆角 | 顶沿圆角 | `edge_fillet.top` | 滑块上限跟随壁厚联动（`wall/2`），拖到头也不会崩 |
| 圆角 | 底沿圆角 | `edge_fillet.bottom` | 上限跟随高度/长宽联动 |
| 隔板 | 启用隔板 开关 | `partitions` 是否为 `null` | 关掉整个文本框会被忽略，等价于没有隔板 |
| 隔板 | partitions 文本框 | `partitions` | 直接写 YAML，支持完整递归语法（见 §4.2），语法错了会在侧边栏报红 |
| 药丸镂空 | 孔大小 | `hollow.hole_size` | — |
| 药丸镂空 | 边框宽度 | `hollow.border` | 下拉选 `auto` 或"自定义"，选自定义才出现滑块 |
| 药丸镂空 | 底面镂空 / 隔板镂空 | `hollow.faces.bottom/partitions` | 两个独立勾选框 |
| 导出 | STL 精度 / 文件名 | `export.tolerance/filename` | — |

右侧主区域：

- **3D 预览**：鼠标左键拖动旋转视角，滚轮缩放。每次改动左侧参数都会重新建模（会有短暂延迟，CadQuery 布尔运算不是瞬间完成的），预览自动刷新
- **统计信息**：外部尺寸、体积、"是否合法几何"（`OK` 表示 CadQuery 内核确认这是个合法实体，可以放心导出打印；如果出现 `FAIL` 说明当前参数组合产生了非法几何，需要调整参数，通常是隔板位置冲突或圆角半径过大导致）
- **下载 STL 按钮**：点击直接下载当前预览对应的模型文件

**为什么隔板用文本框而不是纯滑块**：递归 BSP 树本质上是不定层数的树结构，很难用固定数量的滑块表达"任意深度、任意位置继续细分"这种能力。用 YAML 文本框既保留了命令行版本的完整表达力，也比要点很多层菜单来构建树更快。如果你只是想要标准的田字格/九宫格，直接照抄 §4.2 的示例改数字即可，不需要理解全部语法。

## 6. 常见问题 / 故障排查

### 6.1 "顶沿圆角设大一点就报错 / 建模失败"

顶口圆角要同时倒**外沿棱**和**内沿棱**两条棱（这样整圈顶口摸起来都是圆润的，不只是外面圆）。这两个圆角从里外两侧往中间"吃"壁厚，半径一旦接近 `壁厚 / 2`，两个圆角的弧面会在薄壁中间相遇，OCCT 内核建不出这种自相交的几何，直接报 `BRep_API: command not done`。

程序已经把安全上限设到 `wall/2 * 0.9`（留了 10% 余量），正常使用滑块不会碰到这个问题；如果手写 YAML 且没走过 UI 的联动上限，注意 `edge_fillet.top` 别超过壁厚一半。

### 6.2 "改了 `hollow.angle` 没生效"

45° 是设计上锁死的值（免支撑打印的关键），程序读到非 45 的值会直接强制改回 45 并打印警告，不是 bug。

### 6.3 "隔板报错 does not fit within span"

说明某个 `split.at` + `split.thickness/2` 超出了它所在区域的范围——常见于比例值算出来的绝对位置离区域边缘太近，或者绝对尺寸（`"30mm"`）本身就比区域还大。检查这个节点所在区域的实际可用宽度（上一层切割后剩多少），把 `at` 往区域中心调一点。

### 6.4 网页版 3D 预览是空白/不显示

预览用的是浏览器端 Three.js（通过 CDN 加载），如果网络无法访问 `cdn.jsdelivr.net`，预览区域会加载失败。这种情况下模型仍然是正确生成的（下方"外部尺寸/体积/是否合法几何"照常显示），只是看不到 3D 图，直接下载 STL 用切片软件预览即可。

### 6.5 `pip install cadquery` 半天装不上 / 报错

- 确认 Python 版本在 3.10~3.13 之间（3.14 目前没有对应的预编译轮子）
- 网络问题可以换成 conda：`conda install -c conda-forge -c cadquery cadquery`
- 装的时候会顺带装 VTK、numpy、scipy 等一堆依赖，体积大，网速慢的时候正常要等几分钟，别中途以为卡住了强行中断

### 6.6 命令行报错 `[error] box length/width must be <= 250.0mm ...`

尺寸超过打印板限制，这是硬性拒绝，不会帮你自动缩小。改小 `box.size` 里的长或宽。

## 7. 打印建议

- 收纳盒是**顶面开口无盖**的设计（这是固定行为，不是参数），打印时开口朝上摆放即可，不需要额外支撑
- 底面/隔板的镂空孔已经是 45° 免支撑设计，正常摆放打印不需要为这些孔单独加支撑
- 如果切片软件仍然提示某处需要支撑，先检查是不是自己把 `corner_radius`、`edge_fillet` 设得太极端导致局部出现了非预期的悬空面，而不是默认关掉自动支撑硬打

## 8. 项目文件结构

```
box_generator/
├── config.yaml              # 命令行模式用的默认配置样例
├── main.py                  # 命令行入口
├── box_builder/
│   ├── body.py               # 盒体本体：圆角 + 抽壳
│   ├── partitions.py         # 递归二分隔板
│   ├── hollow.py              # 45° 药丸镂空
│   ├── validate.py           # 参数校验与安全钳制
│   └── export.py             # STL 导出
└── app.py                    # 网页 UI 入口，运行: streamlit run app.py
```

命令行和网页 UI 共用 `box_builder/` 里的同一套建模逻辑，两边参数语义完全一致，YAML 里能写的网页 UI 的文本框（隔板部分）也能写。
